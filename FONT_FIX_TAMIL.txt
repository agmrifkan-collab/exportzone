EXPORT ZONE — COMPLETE WEBSITE UPLOAD (Tamil)

இந்த ZIP-ல் முழு website-மும் `fonts` folder-மும் உள்ளன.

Upload செய்யும் முறை:
1. ZIP-ஐ உங்கள் கணினியில் Extract செய்யவும்.
2. GitHub repository: https://github.com/agmrifkan-collab/exportzone/
3. Add file -> Upload files தேர்வு செய்யவும்.
4. Extract செய்த folder-க்குள் உள்ள எல்லா website files-ஐயும் தேர்வு செய்து upload செய்யவும். `fonts` folder-ஐயும் சேர்க்கவும்.
5. `index.html` மற்றும் `service-pages.css` பழைய கோப்புகளை புதிய கோப்புகளால் மாற்றவும்.
6. GitHub-ல் `fonts/MaruFoPro-Regular.otf` போன்ற நான்கு font files உள்ளனவா பார்க்கவும்.
7. Commit changes செய்து GitHub Pages deployment முடியும் வரை காத்திருக்கவும்.
8. இந்த URL-ஐத் திறந்து font file load ஆகிறதா சோதிக்கவும்:
   https://agmrifkan-collab.github.io/exportzone/fonts/MaruFoPro-Regular.otf
9. Website-ஐ திறந்து Ctrl+F5 அழுத்தவும்.

கவனம்:
- ZIP-ஐ repository-க்கு நேரடியாக upload செய்ய வேண்டாம்; முதலில் Extract செய்யவும்.
- `fonts` folder-ஐ அதன் பெயருடன் repository root-ல் வைத்திருக்க வேண்டும்.
- `EZ Logo.png` கோப்பை நீக்க வேண்டாம்.
- Public website-ல் font files வெளியிட உங்கள் font licence அனுமதிக்கிறதா உறுதிப்படுத்தவும்.
