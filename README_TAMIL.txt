EXPORT ZONE – Japanese SEO Service Pages

உள்ளடக்கம்: 6 SEO HTML pages, shared CSS, sitemap.xml, robots.txt.

GitHub Pages-ல் சேர்ப்பது:
1. GitHub-ல் உங்கள் exportzone repository திறக்கவும்.
2. Add file > Upload files தேர்வு செய்யவும்.
3. ZIP-ஐ உங்கள் கணினியில் extract செய்து, அதிலுள்ள 6 HTML files, service-pages.css, sitemap.xml, robots.txt ஆகியவற்றை repository root-ல் upload செய்யவும்.
4. Commit changes அழுத்தவும்.
5. EZ Logo.png repository root-ல் இருப்பதை உறுதிசெய்யவும். கோப்பு பெயர் வேறாக இருந்தால் HTML-ல் ./EZ%20Logo.png path-ஐ மாற்றவும்.
6. GitHub Pages deploy முடிந்ததும் புதிய URL-களைத் திறந்து சோதிக்கவும்.
7. Homepage index.html-இல் உள்ள navigation அல்லது 買取品目 பகுதியில் புதிய service pages-க்கு links சேர்க்கவும்.
8. Google Search Console > Sitemaps-ல் sitemap.xml submit செய்யவும். பிறகு URL Inspection மூலம் புதிய URL-களை test செய்து Request Indexing செய்யலாம்.

முக்கியம்: index.html-ஐ இந்த ZIP-இல் உள்ள கோப்புகளால் மாற்ற வேண்டாம். Sitemap-ல் homepage மற்றும் 6 புதிய பக்கங்களும் சேர்க்கப்பட்டுள்ளன. Logo file பெயர் வேறாக இருந்தால் logo path-ஐ சரிசெய்யவும். Google indexing/ranking உடனடியாக அல்லது உறுதியாக நடக்கும் என உத்தரவாதம் இல்லை.
