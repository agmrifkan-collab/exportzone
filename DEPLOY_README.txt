EXPORT ZONE GitHub Pages - deployment bundle

Included:
- index.html: updated copy of your existing homepage, preserving its design and content and adding links to service detail pages
- six Japanese SEO service pages
- service-pages.css
- sitemap.xml with homepage and six service pages
- robots.txt
- README_TAMIL.txt from the service-page package

Deployment steps:
1. Open https://github.com/agmrifkan-collab/exportzone/
2. Download/extract this ZIP on your computer.
3. Upload the files inside this ZIP to the repository root using Add file > Upload files.
4. If GitHub asks to replace index.html, that is intended: this index.html is the updated homepage based on the file you supplied.
5. Keep your existing EZ Logo.png in the repository root. The uploaded homepage uses an embedded logo in its visible header, while the SEO service pages reference EZ Logo.png.
6. Commit changes and wait for GitHub Pages to deploy.
7. Open each new service URL to test. Then use Google Search Console URL Inspection and Request Indexing for the new pages, and submit/update sitemap.xml.
